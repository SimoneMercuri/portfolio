05 · Principles

Colour does the work. Each category is a full-bleed panel. One ink colour + one contrast word colour per panel — no gradients, no photos needed.
One giant word per panel. The category name, set huge in the didone, bleeds off an edge. It’s the signature move — never more than one.
Serif sings, grotesque informs. DM Serif Display for the romance (words, kickers); Archivo caps for names, prices and every functional label.
The tool is neutral, the menu is loud. Tavola’s chrome stays quiet grey + slate so each client’s theme — like Salento — carries all the personality.
